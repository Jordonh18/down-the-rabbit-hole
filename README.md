# down-the-rabbit-hole

I keep doing the count in my head and getting a different answer, which is why I am putting it here where I can see it. There were thirteen when I started. There are still thirteen. I am not changing that sentence again.

The program records what I saw and how far down it went. It is not clever. It only remembers one correct thing at a time.

```text
node index.js
node rabbit.js <answer>
```

If it stops listening, `node rabbit.js --reset` puts it back where it began.
